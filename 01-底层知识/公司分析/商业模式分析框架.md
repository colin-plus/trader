# 商业模式分析框架

> 用一张九宫格回答"企业如何创造、传递并获得价值"：客户是心脏、收入是动脉；任何一格变化都会牵动其他格。源自《商业模式新生代》（奥斯特瓦德、皮尼厄），是基本面分析中"商业模式拆解"环节的方法论底座。

## 核心框架：商业模式画布

**定义**：商业模式描述的是一个组织**创造、传递以及获得价值**的基本原理。三件事对应画布的三块：创造与传递（右半：价值主张与客户）、成本与基础设施（左半）、收入（收入端）。

**九宫格图示**：

```
┌────────────┬────────────┬────────────┐
│ 重要伙伴 KP │ 关键业务 KA │ 客户关系 CR │
│            ├────────────┼────────────┤
│            │ 核心资源 KR │ 渠道 CH     │
│            ├────────────┼────────────┤
│            │ 价值主张 VP │ 客户细分 CS │
├────────────┴────────────┴────────────┤
│ 成本结构 C$          │ 收入来源 R$   │
└──────────────────────────────────────┘
```

**九大模块 = 四个部分**：

| 部分 | 模块 | 回答的问题 |
|---|---|---|
| 客户侧（右半） | 客户细分、价值主张、渠道、客户关系、收入来源 | 为谁创造价值、创造什么价值、如何传递与收费 |
| 基础设施侧（左半） | 关键业务、核心资源、重要伙伴 | 靠什么支撑价值的创造与传递 |
| 金融能力侧 | 成本结构 | 价值传递的成本代价 |

**两条主线**：客户是商业模式的心脏（起点永远是"为谁创造价值"），收益来源是动脉（终点永远是"如何把钱收回来"）。九格拼成一张画布，任何一格变化都会牵动其他格。

## 九要素逐项解释与分析要点

### 1. 客户细分（CS）——心脏
- **解释**：回答"为谁创造价值"。客户洞察的核心不是问客户要什么——"要是我去问客户他们想要什么，他们会要一匹更快的马"（福特）；创新的真正挑战在于深入理解客户，而不是简单地问他们要什么。
- **分析要点**：能用"移情图"做客户素描（环境、日常工作、担忧、渴望）。对投资而言这是"第二增长曲线"分析的理论根据：公司当下的现金流由金牛客户贡献，但决定估值天花板的往往是被现有产品结构忽视的新客户群体。

### 2. 价值主张（VP）——想象"不存在的东西"
- **解释**：设计师的工作是挑战思维边界、创造新的选择，这需要有能力去想象"不存在的东西"；商务人士不应只理解别人的设计，自己就应成为设计师。
- **分析要点**：区分公司的价值主张是"更快的马"（同质化改良，护城河浅）还是"汽车"（重构了客户完成任务的成本与体验）。

### 3. 渠道（CH）——传递价值的通路
- **解释**：客户侧模块之一，承载"传递价值"。源笔记未单独展开，但东方财富示例给出了判断：用"流量入口 + 低边际成本的 IT 系统"替代线下营业网点，是把获客与交付通道线上化的渠道设计。
- **分析要点**：渠道结构决定触达成本与转化效率，且直接联动成本结构——低成本渠道是"低佣金—多客户"正循环的前提。

### 4. 客户关系（CR）
- **解释**：客户侧模块之一。源笔记未展开；在画布中与客户细分共同回答"如何获得并留住客户"。
- **分析要点**：判断客户关系依附于哪类群体——依附金牛客户的模式，容易掉进金牛客户陷阱（见下文）。

### 5. 收入来源（R$）——动脉
- **解释**：回答"如何把钱收回来"。三种典型结构各有成本前提：
  - **多边平台**：把两个或更多独立但相互依存的客户群体连接起来，通过充当连接群体的媒介创造价值；平台对单个用户群体的价值，本质上取决于"另一群体"的用户数量（跨边网络效应）。代价：往往要经历"补贴—收费"的烧钱换增长阶段。
  - **长尾**：靠"低库存成本 + 强大平台"保证小众商品及时触达感兴趣的买家，摊薄小众需求的服务成本。
  - **开放式创新**：由外而内，把企业内部闲置资产（主要是专利和技术）变现，对应财报里的技术许可/授权收入科目。
- **分析要点**：先看动脉有几条、是否只有一条；再看每条动脉属于哪种收入模式，其成本前提是否成立。

### 6. 核心资源（KR）
- **解释**：基础设施侧模块，支撑价值创造与传递的资产。源笔记的实证：东方财富以流量入口和低边际成本的 IT 系统为核心资源。
- **分析要点**：核心资源是否构成护城河（流量入口 vs 可复制的普通资产）；资源能否同时支撑现有金牛业务与未来新业务。

### 7. 关键业务（KA）
- **解释**：基础设施侧模块之一。源笔记未展开；在画布中代表公司必须做好的核心动作。
- **分析要点**：结合价值主张判断——宣称的"价值创新"是否有对应的关键业务支撑，还是仅停留在口号。

### 8. 重要伙伴（KP）
- **解释**：基础设施侧模块之一。源笔记未展开；代表价值网络中的外部协作方。
- **分析要点**：伙伴关系是否被替代成本（转换成本）锁定，如平台上的商户、数据源、代销渠道等。

### 9. 成本结构（C$）——金融能力侧
- **解释**：九模块的金融能力部分，承接左半基础设施的全部代价。长尾模式要求低库存成本；平台的规模效应体现为边际成本递减。
- **分析要点**：成本结构是与同行对照的试金石——若声称"价值创新"但成本结构与老牌玩家毫无二致，多半只是在红海里打价格战（蓝海检验，见下）。

## 收入模式对比

| 模式 | 价值来源 | 成本前提 | 财报映射 |
|---|---|---|---|
| 多边平台 | 连接两个以上相互依存的客户群体；跨边网络效应 | "补贴—收费"的烧钱换增长阶段 | 佣金/交易手续费、广告、抽成 |
| 长尾 | 覆盖小众需求，弱化爆款依赖 | 低库存成本 + 强大分发平台 | 长尾 SKU 收入、订阅/服务费 |
| 开放式创新 | 把内部闲置资产（专利、技术）变现 | 研发沉淀形成可授权资产 | 技术许可/授权收入 |

## 常见陷阱与生命周期

### 金牛客户陷阱
能拉动未来增长的客户往往**不是今天的金牛客户**，商业模式创新不能只聚焦现有客户群体，必须着眼于新客户群体。投资含义：当下的现金流由金牛客户贡献，但增长引擎是否已切换、新客户群体是否被现有产品结构忽视，直接决定估值天花板。

### 生命周期评估
- 成功商业模式的生命周期往往比想象中**短**；定期评估商业模式是重要管理活动——评估市场地位的健康程度并做出调整，像体检一样动态迭代，而非一次定型。
- 两个常见错误：
  1. **短期利益导向**：期望新业务第一年就贡献很高收入/大额净增长（大企业惯性）。
  2. **旧架构承载新模式**：沿用旧商业模式的组织架构去承载新业务——新老模式独立运营还是整合，本身就是需要专门决策的问题。
- 附：变革的最大障碍在组织内部。商业模式创新的最大挑战不是技术，而是人与组织的惯性——阻力来自"不懂"（缺统一框架和语言）、"不会"（缺系统观察能力）、"不愿意"（缺紧迫感），新模式还常与旧模式争夺资源、文化和客户。

### 蓝海检验（画布左右联动）
改变右半（价值、客户）必然传导到左半（成本、基础设施）。判断一家公司是否真在做"价值创新"：看其成本结构与行业老牌玩家是否显著不同。雷同即红海价格战，差异化才可能开辟新行业。

## 交易应用：用画布分析 A 股公司的步骤清单

1. **先画九宫格**：按"客户侧（右半）—基础设施侧（左半）—金融能力侧（成本）"填空，不要先谈估值。
2. **右半：为谁创造价值**：列出客户细分，明确谁是金牛客户、谁是被忽视的新客户群体（第二增长曲线在哪）。
3. **价值主张定性**：是"更快的马"（改良）还是"汽车"（重构任务成本与体验）？
4. **渠道与客户关系**：怎么触达、怎么留存，渠道结构是否天然低成本。
5. **收入端找动脉**：收入来源有几条；每条属于平台/长尾/开放式创新哪种模式，成本前提是否成立；是否只有一条动脉。
6. **左半：资源与成本是否自洽**：核心资源、关键业务、重要伙伴能否支撑右半的承诺；成本结构与同行是否显著不同（蓝海检验）。
7. **陷阱检查**：是否掉进金牛客户陷阱（增长引擎没切换）；画布上一次评估是什么时候，佣金率下行、新规等外部冲击下是否需要迭代。
8. **再谈估值**：左右半自洽 + 收入端有第二条动脉，才值得进入估值环节。

**示例：东方财富（300059）**
- 客户细分：股吧/东财社区的个人投资者、天天基金的基金购买者、Choice 数据终端的企业客户三类群体。
- 价值主张："看资讯—聊股票—开户交易—买基金"一站式闭环，免费资讯引流、交易与代销收费。
- 收入来源：证券经纪佣金、基金代销尾佣、金融数据服务与广告——客户是心脏，佣金与尾佣是动脉。
- 核心资源与成本结构：以流量入口和低边际成本的 IT 系统替代线下营业网点，佣金率压到行业最低；低成本吸引更多客户，形成左右半正向联动——"改变右半必然牵动左半"的实证。
- 陷阱提醒：① 增长引擎已从经纪（金牛）转向基金代销与买方投顾等新客户群体；② 佣金率下行与新规冲击下，画布必须持续迭代评估。
