# 安全边际评估框架

> 安全边际 = 内在价值 − 买入价格。概念来自 [[安全边际]]（认知库），本文是**实操落地版**：散户如何用可获取的数据评估一支股票有没有安全边际。核心思想：用 50 美分买价值 1 美元，折扣为估值错误、判断错误、市场下跌留出缓冲。

## 一句话定位

安全边际不是"便宜"，而是"容错率"——折扣买的不只是收益空间，更是犯错后的生存空间；评估安全边际 = 用三把尺子估保守价值，再要求至少 30% 的折扣。

## 核心框架：四步法

```
第1步 定性筛查  公司质地过关吗？         → 不过关：直接排除（价值陷阱）
第2步 三尺估值  三把尺子交叉估内在价值   → 至少两把亮"低估"
第3步 折扣纪律  要求折扣 ≥ 30% 才买入    → 折扣不够：持币等待
第4步 陷阱过滤  便宜的原因审查           → 有雷：再便宜不碰
```

## 知识点

### 一、概念本质：错误缓冲区（三层含义）

- 安全边际为三层错误留缓冲：**估值会错**（估算误差）、**判断会错**（基本面恶化）、**市场会错**（买入后继续跌）
- 安全边际随价格动态变化：跌出边际 = 机会（价格向价值靠拢），涨出边际 = 风险（远离价值）
- 追热点/买贵 = 主动放弃安全边际；"下跌途中接飞刀"的根源是没有价值锚，只有价格下跌带来的"感觉便宜"
- **适用边界**：只对"有内在价值可估"的公司有效——亏损/概念股（无盈利锚）、周期股顶部（盈利最好时 PE 最低最危险）失效

### 二、第 1 步：定性筛查（安全边际的前提）

垃圾公司再便宜也是价值陷阱——便宜是因为该便宜。三指标快速筛查：

| 指标 | 合格线 | 说明 |
|------|--------|------|
| ROE | ≥ 10%（连续 5 年） | 盈利能力的稳定性 |
| 负债率 | 行业可接受（银行天然高负债除外） | 财务风险 |
| 经营现金流 | 常年为正，≈ 净利润 | 利润真实性（防纸面利润） |

### 三、第 2 步：三把尺子交叉估值

**尺子 A：股息率法**（现金流视角，最适合稳健标的）

```
股息率 = 每股分红 ÷ 股价
安全边际判断：股息率 ≥ 10 年期国债收益率 × 1.5
当前参考：国债约 1.7%，×1.5 ≈ 2.5% → 股息率 ≥ 3% 才有讨论价值
```

- 适用：银行/公用事业/高分红蓝筹（现金流稳定、分红确定）
- 案例：成都银行每股分红约 0.6-0.7 元，18.79 买入 → 股息率约 3.2-3.7%，及格但不算高安全边际

**尺子 B：估值分位法**（相对自身历史）

```
当前 PE/PB 在近 5-10 年历史分位
安全边际判断：分位 < 30% = 低估区；> 70% = 高估区
```

- 免费工具：理杏仁、韭圈儿、且慢估值
- 局限：分位是"相对自己历史"而非绝对价值——一直贵的公司 30% 分位仍可能贵

**尺子 C：PB 净资产法**（兜底视角）

```
PB = 股价 ÷ 每股净资产
PB < 1（破净）= 以低于账面资产买入
```

- 银行股天然低 PB（成都银行约 0.9），但破净 ≠ 安全——须结合资产质量（不良率）看

### 四、第 3 步：折扣纪律

- 三把尺子**至少两把同时亮"低估"**才考虑买
- 格雷厄姆标准：折扣 ≥ 1/3（价格 ≤ 内在价值 2/3）；现代宽松取 **≥ 30%**
- 买入后安全边际消失（涨 30%+）→ 重新评估是否卖出（对接 [[价值基准]]）

### 五、第 4 步：价值陷阱过滤器

便宜的原因三问：

1. **为什么便宜？** 行业衰退/政策风险/财务造假嫌疑 → 便宜是合理的，别买
2. **盈利真实吗？** 应收账款暴增/经营现金流长期为负 → 利润可能是纸面的
3. **管理层诚实吗？** 频繁减持/商誉雷/关联交易 → 再便宜不碰

## 与交易体系的结合

- **安全边际适合"底仓"决策，不适合"做 T"**：做 T 是价格博弈不需要安全边际；底仓建仓/加仓时机用安全边际过滤
- 建底仓但安全边际不足（如成都银行建仓）→ 定位为"观察仓"，仓位控制 + 后续加仓等更好价格
- 数据栈落地：TideScope finance 表可加 `valuation` kind（PE/PB/股息率/历史分位），财务数据页做"安全边际仪表盘"
