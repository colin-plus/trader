# 个股档案

> 深度研究过的公司的专属档案，沉淀深度认知的地方。

## 目录结构

每家公司一个独立文件夹，建议命名为「公司名（股票代码）」：

```
个股档案/
└── 贵州茅台（600519）/
    ├── 贵州茅台（600519）.md   ← 总览：业务、财务、估值、核心逻辑
    ├── 财报分析.md
    ├── 研报摘要.md
    ├── 业绩会纪要.md
    └── 跟踪日志.md
```

## 使用规则

- 只收录**深度研究过**的公司，普通资料放 [[02-市场研究]] 其他目录
- 跟踪逻辑终结（不再关注）后，整个文件夹移入 [[99-归档]]
- 定期更新跟踪日志，保持档案是"活"的
