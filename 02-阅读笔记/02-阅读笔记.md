# 02-阅读笔记 (Reading)

> 书架层：每本书一篇，记录阅读状态与完整总结。这里是**原料仓**；提炼出的可复用知识点按主题归入 [[01-底层知识]]。
> 流转：书 → 总结 → 提炼知识点 → 01-底层知识。
> 目录按**开始阅读年份**分（依据微信读书划线时间）：`2023/ 2024/ 2025/ 2026/`。

## 阅读状态

- frontmatter 字段 `read_status`: `在读` / `读完` / `弃读`
- 用 Databases 视图按 read_status 筛选出书单（见 [[查询]]）
- 没读完的书只总结已读部分，别假装总结了全书；重点章节以后回读补摘

## 总结规范（每篇必备）

1. **一句话总结** — 如果只能记住一句
2. **核心框架** — 按书的目录脉络（目录是作者思路的地图）
3. **精华要点** — 转述为主 + 原文引用佐证，不罗列划线
4. **与交易的联系** — 落到 A 股场景
5. **行动项** — 要验证的方法、要回读的章节
