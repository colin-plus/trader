# 个股档案

> 深度研究过的公司的专属档案，沉淀深度认知的地方。

## 目录结构

每家公司一个独立文件夹，建议命名为「公司名（股票代码）」，分析类文件按日期命名可累积多次分析：

```
个股档案/
└── 贵州茅台（600519）/
    ├── 贵州茅台（600519）.md   ← 总览：业务、财务、估值、核心逻辑（事实快照）
    ├── 分析-YYYY-MM-DD.md   ← 深度分析：结论先行，核心发现 + 持仓/决策核对（判断产物，可多篇）
    ├── 财报分析.md
    ├── 研报摘要.md
    ├── 业绩会纪要.md
    └── 跟踪日志.md           ← 活日志：走势、公告、待验证项
```

## 使用规则

- 只收录**深度研究过**的公司，普通资料放 [[03-市场研究]] 其他目录
- 跟踪逻辑终结（不再关注）后，整个文件夹移入 [[99-归档]]
- 定期更新跟踪日志，保持档案是"活"的
