# 金溢科技（002869）

> 一句话逻辑：ETC 与智慧交通装备厂商，主业连续两年下滑（2025 年归母净利 −1.30 亿、2026H1 −0.39 亿）；技术面 10-08 涨停突破，属**低价 + 车路云题材**驱动，亏损与并购业绩补偿未收回是硬约束。

## 业务与行业

- 主营：智慧收费（ETC 终端 + 路侧）占 2026H1 收入 **67.9%**（1.24 亿）、汽车电子 20.0%、智能网联/物联网约 2.4%
- 客户：高速公路运营方、车厂；正设合资公司（佛山金溢领充，持股 65%）向充电桩/储能等"交能融合"转型
- 行业：智能交通 / 计算机设备（ETC、车路云）
- 上市：深交所主板 2017-05-15

- 看点：① ETC 主业毛利率仍有 33.7%，是同业中较硬的资产；② 向路侧/车路云、"数字能源、交能融合"转型；③ 股权激励 8.48 元/股绑定团队；④ 低价小市值易被题材资金拉动
