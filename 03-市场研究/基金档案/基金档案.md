# 基金档案

> 深度研究过的基金的专属档案（含 ETF、指数基金、主动基金），沉淀对基金的深度认知。

## 目录结构

每只基金一个独立文件夹，建议命名为「基金名称（代码）」：

```
基金档案/
└── 沪深300ETF（510300）/
    ├── 沪深300ETF（510300）.md   ← 总览：类型、规模、费率、跟踪标的、核心逻辑
    ├── 跟踪分析.md
    ├── 基金经理研究.md           ← 主动基金适用：经理风格、持仓偏好、任期业绩
    └── 跟踪日志.md
```

## 使用规则

- 只收录**深度研究过**的基金；普通资料放 [[03-市场研究]] 其他目录
- 研究逻辑终结（不再关注）后，整个文件夹移入 [[99-归档]]
- 定期更新跟踪日志，保持档案是"活"的
