# frontmatter 规范

> 全库统一的笔记元数据（YAML frontmatter）约定。字段是数据库视图与统计的数据基础，与 [[标签体系]] 配套使用。

## 设计原则

1. **文件名就是标题**，不设 title 字段
2. **分类信息只用标签表达**（状态/行业/策略/来源等），字段里不重复存放，避免双份数据不同步
3. **字段只放标签表达不了的标量**：代码、日期、枚举状态
4. **空字段直接省略**，不写 null；字段名小写英文，值用中文，日期统一 YYYY-MM-DD

## 核心字段（所有笔记）

| 字段 | 必填 | 说明 |
| ---- | ---- | ---- |
| type | 是 | 笔记类型，见下方枚举 |
| created | 是 | 创建日期 YYYY-MM-DD，Templater 自动生成 |
| updated | 是 | 最后更新日期 YYYY-MM-DD，手动维护或 Linter 自动 |
| tags | 内容笔记必填 | 标签数组，遵循 [[标签体系]]；索引/规范类元笔记可省略 |

### type 枚举

- `学习笔记` — 01-底层知识（哲学/宏观/公司/技术/心理）
- `研究笔记` — 02-市场研究（行业、政策、题材）
- `档案` — 02-市场研究（个股档案、基金档案）
- `复盘` — 03-复盘与计划
- `交易计划` — 03-复盘与计划
- `收件箱` — 00-收件箱
- `索引` — 目录索引笔记（Home、各目录同名笔记）
- `规范` — 05-基础设施的规范文档（标签体系、frontmatter 规范）

## 扩展字段（按需，不涉及就不写）

| 字段 | 适用 | 说明 |
| ---- | ---- | ---- |
| ticker | 档案、交易计划 | 股票/基金代码，如 600519、510300 |
| board | 档案（可选） | 主板 / 创业板 / 北交所 / 科创板 |
| status | 交易计划 | 待触发 / 已触发 / 已失效 |
| read_status | 阅读笔记 | 在读 / 读完 / 弃读 |
| period | 复盘 | 日复盘=日期，周复盘=周一日期，月复盘=YYYY-MM |
| aliases | 档案（推荐） | Obsidian 原生别名，用于链接与搜索 |

### aliases 与 title 的区别

- `aliases` 是 Obsidian **内置字段**：给笔记定义别名，`[[别名]]` 链接和快速切换都能命中。例：档案文件名「贵州茅台（600519）」，写 `aliases: [贵州茅台, 茅台]`，之后 `[[茅台]]` 也能跳转
- `title` 不是 Obsidian 内置字段（只是部分插件/主题的展示约定），且文件名已是标题，故不设

## 示例

### 学习笔记

```yaml
---
type: 学习笔记
created: 2026-08-11
updated: 2026-08-11
tags: [知识/原理, 分析/技术面, 来源/书籍]
---
```

### 个股档案

```yaml
---
type: 档案
ticker: 600519
board: 主板
aliases: [贵州茅台, 茅台]
created: 2026-08-11
updated: 2026-08-11
tags: [状态/观察中, 类型/股票, 市场/A股, 行业/消费]
---
```

### 基金档案

```yaml
---
type: 档案
ticker: 510300
aliases: [沪深300ETF, 300ETF]
created: 2026-08-11
updated: 2026-08-11
tags: [状态/观察中, 类型/基金/ETF, 市场/A股]
---
```

### 复盘（周）

```yaml
---
type: 复盘
period: 2026-08-10
created: 2026-08-11
updated: 2026-08-11
tags: [复盘/周]
---
```

### 交易计划

```yaml
---
type: 交易计划
ticker: 600519
status: 待触发
created: 2026-08-11
updated: 2026-08-11
tags: [策略/趋势跟踪, 类型/股票]
---
```

### 收件箱

```yaml
---
type: 收件箱
created: 2026-08-11
updated: 2026-08-11
tags: [待处理, 来源/文章]
---
```

## Databases 配套用法（官方核心插件，本库采用）

- 命令面板 → 新建数据库视图，来源选文件夹或标签，列选 frontmatter 字段
- 常用列：type、ticker、board、created、updated、period、status（交易计划）
- 常用筛选：type = "复盘"；tags 含 状态/观察中；status = 待触发
- 视图可嵌入笔记（命令面板 → 嵌入数据库视图），是 Dashboard 的推荐方式
- 注：早期草案中的 Dataview 语法示例已停用，本库以 Databases 为准
