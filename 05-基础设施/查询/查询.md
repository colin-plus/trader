# 查询

> Databases（数据库）是 Obsidian **官方核心插件**（设置 → 核心插件 → Databases，本库已启用），用 UI 从 frontmatter 字段生成数据视图。它是本库 Dashboard 的数据引擎。

## 使用方法

1. 命令面板（Cmd+P）→ 新建数据库视图
2. 选择数据来源：文件夹（如 02-市场研究/个股档案）或标签（如 #状态/观察中）
3. 列 = frontmatter 字段（ticker、board、created、period、status…），可加标签列
4. 设置筛选 / 排序 / 视图格式（表格、看板、日历）
5. 视图可嵌入任意笔记：命令面板 → 嵌入数据库视图

## 说明

- 视图依赖笔记 frontmatter 中的规范字段（见 [[frontmatter 规范]]）与 [[标签体系]] 中的标签——**写模板时约定好字段，视图才能统一展示**
- 交易执行数据（持仓、盈亏）在券商/Excel 管理，不进入知识库，因此视图不做盈亏统计
- 视图保存在笔记中，随库同步
