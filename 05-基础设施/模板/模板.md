## 使用方式

1. 安装社区插件 **Templater**，设置 → Templater → Template folder location 指向 `05-基础设施/模板`
2. 新建笔记后：`Cmd/Ctrl+P` → `Templater: Insert template` → 选择对应模板
3. 进阶：Templater 可配置「新建笔记时自动套用模板」（按文件夹映射，如 02-市场研究/个股档案 → 个股分析模板）
4. 模板里的 `<% ... %>` 是 Templater 变量（自动填日期、文件名），未装插件时显示为原文，不影响手动填写
