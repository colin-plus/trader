## 语法速记（踩坑总结）

- 语言名是 `base`（不是 database）；内容是 **YAML**（不是 JSON）；顶层键：`views`/`filters`/`formulas`/`properties`/`summaries`
- **没有 source/from**：数据库默认包含全库文件，靠 `filters` 缩小范围
- filters 表达式：`type == "档案"`、`file.name != "跟踪日志.md"`（file.name 含扩展名）、`file.inFolder("02-阅读笔记")`、`file.hasTag("...")`
- 公式列：`formulas:` 定义（`ticker: ticker` = 公式名: 表达式），`properties: formula.ticker: {displayName: 代码}` 配显示名
- 属性引用：`note.X`（简写 X）、`file.X`、`formula.X`；日期运算 `today()/now()`；比较 `== != > < >= <=`；布尔 `! && ||`

## 使用方法

1. 命令面板（Cmd+P）→ Create new base（新建 .base 文件）或 Insert new base（嵌入代码块）
2. 筛选/排序/列在 UI 里配置，改动会自动写回 .base 文件/代码块——**想学官方格式就让 Obsidian 生成，再读文件**（最可靠的格式来源）
3. 视图可嵌入任意笔记：`![[文件名.base#视图名]]`

## 说明

- 视图依赖笔记 frontmatter 中的规范字段（见 [[frontmatter 规范]]）与 [[标签体系]] 中的标签——**写模板时约定好字段，视图才能统一展示**
- 交易执行数据（持仓、盈亏）在券商/Excel 管理，不进入知识库，因此视图不做盈亏统计
- 视图保存在笔记中，随库同步
