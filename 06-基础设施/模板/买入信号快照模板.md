# 买入信号快照模板

> 扣扳机之前填。**目的不是"证明该买"，而是把"我在猜"和"我算过"分开**——填完还答不出证伪条件，这笔就不买。
> 本模板对应 [[买卖规则]] 的「买入信号清单」，是 [[选股模型]]《第二层次思维 8 问》三关之后的**执行层**闸门：8 问管"要不要为这只票做研究"，本模板管"此刻要不要下单"。

## 为什么需要它

现有买入过程依赖四类模糊动作——查看资金流向、查看 K 线趋势、了解最近新闻、猜主力与散户心理。这四类**全部落在"时机"这一侧**，缺三样承重结构：

1. **没有估值锚** → "便宜/贵"无法判定（见 [[价值足够性]]：不求算准，只求判断够不够便宜）
2. **没有证伪条件** → "主力还在不在"没有反例，所以永远不会错（最危险的状态）
3. **没有仓位算术** → 买多少全凭感觉

按下文顺序填，逐项消灭这三个空缺。

## 填写约定

- **不确定就写"不知道"**，别拿感觉填空——编一个数字比留空危险得多
- 带 ⚠️ 的项没有合格答案时，**建议不买**（不是"再研究研究"）
- 一张快照对应一笔买入决策；加仓、做 T 另开一张
- 数据来源记为事实，推断来源记为推断（[[第二层次思维]]：共识内的信息不产生超额收益）

> 过关才往下填。**8 问的 3 个硬门槛是主线，本模板只补执行层的判断依据。**

- [ ] 机会类型：A 低估持有 / B 周期反转 / C 成长兑现 / D 危机 ← 决定下面每项怎么读，见 [[#机会类型与闸门参数]]
- [ ] 我买它的**唯一主要理由**（一句话，不许写三条）：
- [ ] 这个理由属于哪一类**结构性优势**——期限 / 规则 / 心理？（说不出 → 无优势，[[第二层次思维]] 三关之一）
- [ ] ⚠️ **若三周后跌 15%**，我依据什么判断是"逻辑破了"还是"只是波动"？
- [ ] ⚠️ 我的判断与共识差在哪、量化幅度多少？

> 后两项任一写不出来 → **不买**。这是本模板的核心闸门：写不出证伪条件，等于没有反例，也就无法从结果中学习（[[结果偏差]]）。

> 管"进场成不成势"，**不管"便不便宜"**。禁止用趋势给高价格授权（见 [[最小阻力线]]、[[关键点理论]]）。

## 四、市场心理（把"猜"升级成"测"）

> 不再"猜主力在干什么"，改为**测当前情绪在什么分位**（[[钟摆意识]]、[[心理错误根源]]）。区间取值（0–100）比方向判断可靠。

| 维度 | 可测指标 | 今日读数 | 区间/分位 | 读法 |
|---|---|---|---|---|
| 广度 | 全市场涨停 / 跌停家数 |  |  | 极端值 = 情绪极值 |
| 参与 | 全 A 成交额分位 |  | 近 1 年分位 | 快速抬升 = 拥挤 |
| 杠杆 | 两融余额方向 |  | 近 3 月趋势 | 加速上升 = 自负上升 |

## 五、仓位算术（不是感觉，是除法）

- 单笔最大亏损额（占总资金 %）= ______% → 金额 = ______ 元
- 止损 / 失效位距离（%） = ______%
- **允许股数 = 金额 ÷ (价格 × 距离%)** = ______ 股，取整到 100 股 = ______ 股
- 分批计划：底仓 ______ 股 + 后续 ______ 批，每批触发条件：______
- 仓位上限：占总资金 ≤ ______%（越跌越买时总计不超过此线）

> 算出来的股数小得没意义 → 说明这笔不值得做，或我的资金不适合这个逻辑。**按算术结果决定，不按"很想买"决定**（[[错误边际]]）。

## 机会类型与闸门参数

> 不同机会类型的买入逻辑不同，**混用是主要亏损来源**。先定类型，再决定各闸门怎么读。

| 类型 | 价值闸门（买什么价） | 择时闸门（何时进） | 加仓靠什么 | 失效靠什么 |
|---|---|---|---|---|
| **A 低估持有** | 估值分位 / PB / 股息率 | **不要求突破**；低估区域内分批（[[低估区域]]：接受"次便宜"） | 价格更低或时间 | 基本面恶化（资产质量、盈利能力） |
| **B 周期反转** | `周期位置` + 中周期盈利 / PB | **确认反转后**才进（扭亏、毛利率回升） | 盈利兑现（财报） | 出清失败、二次价格战 |
| **C 成长兑现** | 8 问三关 + 估值锚 | 报平台突破 / 回踩确认 | **只按已兑现财报** | 增速失速、现金流不达标 |
| **D 危机型** | [[危机买入]] + [[等待机会]]（被迫卖家） | 恐慌极值（第四项低分位） | 分批、跌深加 | 现金流断裂风险 |

**混用禁令**：

- 突破买入（利弗莫尔 / 趋势系）**不得**用于 A 类低估票 → 会把"等便宜"变成"追强"
- 破净便宜（价值系）**不得**用于 C 类成长票的接刀 → 会把"成长失速"误判为"打折"
- 做 T 属**执行手段**，不改变底仓逻辑：T 仓独立记账、有明确回补条件，**不得**让"摊成本"退化为无限加仓

## 示例：快克智能 2026-08-28（真实案例，含空缺）

> 用途：演示格式**和一个真实问题**——当时四个决策点都是模糊的，事实自相矛盾（利好 vs 长上影 + 增速落后），而估值闸门完全空缺。

| 项目 | 当日实况 | 状态 |
|---|---|---|
| 机会类型 | 未定性（后补为 C 成长兑现） | ⚠️ 事后才补 |
| 主要理由 | "先进封装题材 + 中报营收 +31.8% 加速" | ✅ |
| 资金流向 | 未记录 | ⚠️ 空缺 |
| K 线 | 08-28 冲高 47.14 回落收 44.00，**长上影**，放量 13.0 万手 | ✅ 与买入理由冲突 |
| 新闻/证伪 | 中报净利 +14.0%，**落后于营收 +31.8%** | ✅ 事后才被写成证伪点 |
| 市场心理 | 未记录 | ⚠️ 空缺 |
| 仓位算术 | 44.46×400 + 44.01×400 = 800 股 | 只有结果，无计算过程 |
| 估值锚 | 未填（当时没有 PE / PB 分位） | ⚠️ 空缺 |

**这个案例的四个问题**（正是本模板要解决的）：

1. **四个决策点全是"看了、感觉可以"**——没有一处留下可复算的依据，"主力/散户在干什么"事后完全无法检验
2. **证据自相矛盾**却仍然买入：利好中报（写成了买入理由）+ 放量长上影（回落 3.1 元，典型的冲高派发形态）
3. **证伪条件与买入理由同源**：笔2 买入理由是"营收加速"，而笔3 的证伪点写的是"净利增速落后营收"——**如果它算证伪，它当初就不该是买入理由**
4. **估值闸门空缺**：48.70 的前高附近，动态 PE 在什么分位？这笔买入**完全没有价格约束**，只剩题材与 K 线

## 使用方式

1. 在 `03-市场研究/个股档案/<标的>/` 或 `04-复盘与计划/交易计划/` 下新建笔记，粘贴本模板内容
2. 按"前置闸门 → 一至四项 → 五仓位 → 六否决"顺序填，**不跳项**
3. 填写完成的快照，把"结论"抄进 `交易计划-XXX-日期.md` 的触发条件里，作为该笔买入的依据留档
4. 卖出后复盘时回看这张快照：**当时的证伪条件是否被触发？我是按它执行的吗？**（这一栏填实，[[买卖规则]] 的卖出清单会自然长出来）
