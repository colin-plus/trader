# 认知库顺序说明

> [[认知库]] 的**线性阅读顺序**及其维护方式。解决两个老问题：
> ① 每条认知原本只有网状链接，顺读时会反复绕回看过的卡片、又有卡片几乎刷不到；
> ② 索引同一概念散落在多个分类里（曾一度 307 条链接挤了 212 个概念），"按分类顺读"实际等于随机。

## 设计：顺序是数据，不是手工清单

顺序**只写在顺序清单里**，由脚本同步到两个地方：

| 落点 | 内容 | 作用 |
| ---- | ---- | ---- |
| 每条笔记的 frontmatter | `认知序号` `认知章节` + 标签 `认知/NNN`、`认知/章节-X` | 让 Obsidian **Databases** 能按序排列/筛选 |
| 每条笔记正文末尾 | 「导航」块：上一条 / 返回目录 / 下一条 + 第 N/208 条 | 顺读不断链，不依赖任何插件 |
| [[认知库]] | 有序目录：8 章 + 序号 + 总览表 | 跳章、总览进度 |

**一条认知只归属一个章节**——这是消除索引重复的根因。跨章概念不再复制链接，而在笔记里用 `**关联**` 互链。

## 章节结构（208 条）

顺序即**学习路径**：从"怎么想"出发，到"买什么"，再到"怎么下手"，最后铺开宏观背景。

| 章 | 章节 | 条数 | 起止 |
| -- | ---- | ---- | ---- |
| 一 | 认知地基 | 31 | 001–031 |
| 二 | 投资本质 | 74 | 032–105 |
| 三 | 决策心法 | 12 | 106–117 |
| 四 | 市场理解 | 29 | 118–146 |
| 五 | 交易执行与纪律 | 15 | 147–161 |
| 六 | 财商与资产 | 32 | 162–193 |
| 七 | 公司与估值 | 1 | 194 |
| 八 | 宏观与周期 | 14 | 195–208 |

> 第七、八章刻意放在最后：公司细节与宏观周期需要前面的估值框架作背景才有意义。

## 三个入口

1. **顺读**（主推）：打开 [[认知库]] 或任意一条认知，一路点「下一条」，001 → 208 不断链
2. **跳章**：[[认知库]] 顶部的「总览」表，点章节名跳到该章锚点
3. **按序检索**：Obsidian → 新建数据库视图 → 来源选标签 `认知` → 按 `认知序号` 升序；或按 `认知章节` 筛选某一章

## 维护

```bash
# 只检查不改动（漏项/死链/重复会报错退出，不写任何文件）
python3 06-基础设施/自动化/scripts/rebuild_认知库导航.py --dry-run

# 写入：同步所有笔记的标签与导航块，并重建 认知库.md
python3 06-基础设施/自动化/scripts/rebuild_认知库导航.py
```

- 顺序清单：`06-基础设施/自动化/scripts/认知库顺序.txt`（**改顺序只改这个文件**，然后重跑脚本）
- 脚本：`06-基础设施/自动化/scripts/rebuild_认知库导航.py`（幂等；导航块由 `<!-- 导航:begin -->` 标记包裹，重跑只替换该块）
- **新增一条认知**：① 复制 [[认知库模板]] 建 `<概念名>.md` → ② 在顺序清单对应章节末尾加一行概念名 → ③ 重跑脚本
- **校验保护**：清单里有多余概念（会变死链）或漏掉文件时，脚本**拒绝写入**并列出差异——先修清单再跑

## 边界与注意

- 导航块**不要手改**，重跑会覆盖；顺序调整请改顺序清单
- 概念名必须与 `01-底层知识/认知库/<概念名>.md` 文件名**完全一致**（含标点），否则脚本报错
- 笔记的 `updated` 字段由 Linter 在保存时刷新；本脚本不碰 `updated`，避免批量改时间戳
- 本次重建前 208 篇已备份至 `/tmp/rz_backup/`（临时目录，重启会清空）
