# 精读提炼 · 命名规范（v1.0）

> 2026-08-21 定稿，基于《安全边际》试点三轮打磨沉淀
> 用途：全量 15 本书精读条目统一命名，支撑跨书概念归并

## 统一格式

```
## N. 概念名：一句话副标题
```

- 概念名 = 书名（记忆锚点）：短、名词性、可检索、可跨书互链
- 副标题 = 副书名（具体说法）：这本书对这个概念的具体说法，看了就懂

---

## 一、概念名原则（冒号前，负责"记"）

1. **名词性**：必须是名词或名词短语。主谓句/动宾句一律提炼（情绪是敌人→情绪控制）
2. **纯名词**：不用 = 号、不用"优于/优先于"类关系词（价值优先→价值基准）
3. **≤8 字**：超过就压缩（复利与亏损的不对称性→亏损不对称性）
4. **来源优先级**：作者原词（安全边际、市场先生）> 书中隐喻（博傻游戏、仓鼠之轮）> 领域通用术语（价值基准、亏损不对称性）
5. **唯一性**：同一概念跨书出现，全库统一用同一个概念名，绝不一书一名——这是跨书归并的锚点

## 二、副标题原则（冒号后，负责"懂"）

1. **看了就懂**：不甩隐喻，点破机制（"是'特洛伊木马'"→"伪分散比集中更危险"）
2. **回答"是什么"**：术语型概念用定义或例子注解（催化剂：让低估的价值尽快得以兑现）
3. **不重复概念名**：副标题不得是同义复述（"催化剂：投资要寻找催化剂" ✗）
4. **忠于原文**：只从该条"解释/应用/原文"提炼，不新增原书没有的观点；≤25 字

## 三、决策优先级（拿不准时按此自决）

1. 已有"概念名:副标题"且都达标 → 原样保留
2. 有概念名但副标题不达标 → 只改副标题
3. 一句话式 → 核心名词提炼概念名，句子其余作副标题
4. 纯名词 → 从解释段提炼副标题
5. 自造名词构造法：核心概念词 + 属性词（价值+基准，亏损+不对称性）
6. 兜底：实在提炼不出 → 用解释段第一句压缩作副标题，概念名用领域通用术语

## 四、跨书归并规则

1. 同名概念统一概念名，副标题保留各书特色说法（同一概念在不同书的侧重点）
2. **认知清单既有命名直接沿用**（安全边际、市场先生、能力圈、损失厌恶…）——被验证过的命名资产，清单归档后名字继续用

## 五、批处理机制（减少交互）

1. 每 3-4 本一批，批内不问
2. 每批交付：命名对照表，分两栏——"已按原则处理" + "存疑待确认"
3. 用户只看"存疑"栏，其余抽查
4. 必问唯一情形：概念名语义边界模糊、且影响跨书归并锚点
